# Ferro · Web y app

Ferro es una marca de **Limly LLC**. Sitio estático: landing, app de modelos financieros y páginas legales, en español, inglés, portugués y francés.

- **Publicar:** sube esta carpeta a GitHub e impórtala en Vercel (Framework: Other, sin build). Ver `GUIA.md`.
- **Configurar:** solo se edita `assets/config.js` (pagos, Firebase, correo). Cada cambio en GitHub se publica solo.
- **Funciona sin configurar:** la app queda abierta y los formularios llegan por correo a `notifyEmail`.
